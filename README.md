# ewyluda.github.io

Serves one file: [`robots.txt`](robots.txt) at the root of `ewyluda.github.io`, the only place
crawlers look for it. The project sites keep their own repositories and paths:

- [AI Infra Monitor](https://ewyluda.github.io/ai-infra-monitor/): AI crawlers and assistants
  refused, per its [terms](https://ewyluda.github.io/ai-infra-monitor/terms.html).
- [GPU Price Index](https://ewyluda.github.io/gpu-price-index/): open to all.

robots.txt binds only crawlers that honour it.
